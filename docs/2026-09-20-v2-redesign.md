# 月亮露馅了·第二版设计定稿

## 产品主线

挑月皮→选主馅→调夹心→处理意外→揉月→压纹→烘烤→切开→看结果。保留原有16种人格分类与七维评分；选择和操作行为继续影响结果，随机掉落的食材本身不计分。

## 视觉方向

- 暖白纸张作底，深棕文字，橘红与钴蓝只用于重点；版式参考食物杂志而非黑金档案馆。
- 标题短，提示说明直接说操作；去掉逐页英文眉题和刻意的句号。
- 月饼采用原创细节插画：花边、饼皮厚度、压纹、烘烤色差和切面可辨认。动效围绕触摸反馈、面团与切面展开，不做冗长过场。
- 控件统一圆角、可见的选中态与禁用态；小屏优先，不依赖远程图片、字体或脚本。

## 交互验收

1. 每页都能看清当前任务、可操作区域和下一步；选皮、选馅、配比、揉面、压纹、烘烤各有即时反馈。
2. 切月饼：月饼上有可见切线，横向划动可切开；手势受系统滚动干扰时仍可点“直接切开”。完成只触发一次，取消手势不会误完成。
3. 结果首屏是适合分享的主卡；证据、配方、关系页保留为可选翻阅内容。16类结果的口吻具体、俏皮、不空泛。
4. 320/375/430宽度通过完整流程，无横向溢出；键盘交互、缓存恢复、本地相册桥接和低动态偏好继续可用。
5. 发布包只包含本地HTML、CSS、JS和图片；运行与测试均不需网络。以准确的最终ZIP运行预检，并区分本地通过与平台上传/真机/审核结果。
